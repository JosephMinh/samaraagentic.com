Privacy & access

Status: prospective

A read-only Gmail assistant, planned for one person’s work administration.

The intended assistant would read and summarize specifically authorized Gmail messages, extract action items, and prepare reply text for human review.

Setup is not active. This website is informational only and does not grant Gmail access.

Today

Nothing is connected.

  • No Gmail permission grant or token exists.
  • No Gmail messages, headers, or attachments have been fetched.
  • Automated monitoring and sending are neither enabled nor authorized.

If separately authorized later

Proposed access is read-only.

The proposed Google permissions are https://www.googleapis.com/auth/gmail.readonly, openid, email, and https://www.googleapis.com/auth/userinfo.email.

Important: the Gmail read-only scope can technically view all messages, settings, and attachments in the selected account. It is not limited to a chosen sender or a selected subset of messages.

That scope does not permit sending mail or changing mail. Any future monitoring or automatic response would require separate, explicit authorization and appropriate permissions.

Before anything changes

Important details still need decisions.

Storage, retention, deletion, backups, logs, token security, external AI-provider handling, and which message excerpts could be shared have not been finalized. The Google app name and a public contact have not been supplied for this site.
