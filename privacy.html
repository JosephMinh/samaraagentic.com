Privacy & access

Setup is not active.

This is an information page for a prospective one-person Gmail assistant. It is not a sign-in page and it cannot grant access to Gmail.

Current status

No Gmail grant or token exists, and no mail has been fetched. Automated monitoring and sending are not enabled or authorized.

Proposed permissions

If the account owner separately authorizes it in the future, the proposed scopes are:

  • https://www.googleapis.com/auth/gmail.readonly
  • openid
  • email
  • https://www.googleapis.com/auth/userinfo.email

The read-only Gmail scope can technically view all messages, settings, and attachments in the selected account. It does not permit sending, deleting, labeling, archiving, marking mail read, or otherwise changing mail.

Google describes Gmail scopes in its Gmail API scope guide.

Intended purpose

The intended use is limited to the account owner’s work administration: reading and summarizing specifically authorized messages, extracting action items, and generating reply text for human review. Generating text does not send it.

What has not been finalized

There is no settled public disclosure yet for where mail-related data would be stored, how long it would be retained, how deletion would work, or how backups and logs would be handled.

Token storage, unlock, and security details have not been configured or verified. The external AI provider, its applicable data handling and log retention, and which message excerpts could be sent to it are also not finalized.

The Google app name and public contact information have not been supplied for publication. These unresolved items need owner and provider review before any mailbox use.

Future revocation

There is no current grant or local token to revoke or remove. If access is granted in the future, the account owner can revoke the app through Google Account third-party connections. If a connector later stores a local token, removing that local token would be a separate step.
