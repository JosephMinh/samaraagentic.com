Privacy & access

Limited read-only access is active.

This is an information page for a one-person Gmail assistant. It is not a sign-in page and it cannot grant access to Gmail.

Current status

One personal account has active Gmail read-only and identity authorization, with a local token. One specifically approved exchange was inspected, and selected excerpts were processed by the assistant’s external OpenAI Codex model provider for that one task.

A bounded detection-only trial is approved. This is not authorization for unrestricted monitoring, and this site does not state that the trial has run or completed.

Active permissions

The active scopes are:

  • https://www.googleapis.com/auth/gmail.readonly
  • openid
  • email
  • https://www.googleapis.com/auth/userinfo.email

The read-only Gmail scope can technically view all messages, settings, and attachments in the selected account. It does not permit sending, deleting, labeling, archiving, marking mail read, or otherwise changing mail.

Google describes Gmail scopes in its Gmail API scope guide.

Intended purpose

The intended use is limited to the account owner’s work administration: reading and summarizing specifically authorized messages, extracting action items, and generating reply text for human review. Generating text does not send it. The only completed authorized use is one approved task: inspecting one specifically approved exchange and processing selected excerpts for that task. The bounded detection-only trial has separate approval, but this site does not state that it has started or completed. Sending and provider-side reply drafts are not authorized.

What has not been finalized

There is no settled public disclosure yet for where mail-related data would be stored, how long it would be retained, how deletion would work, or how backups and logs would be handled.

The existence of a local token does not settle token storage, unlock, security, or rotation details. Apart from the one approved task, general future AI use, provider handling, data handling, log retention, and which message excerpts could be sent to a provider are not finalized.

The Google app name and public contact information have not been supplied for publication. These unresolved items need owner and provider review before any further mailbox use beyond the separately approved bounded trial.

Future revocation

The account owner can revoke the active grant through Google Account third-party connections. Removing the local token would be a separate step.
