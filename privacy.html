Privacy & access

Limited Gmail access is active.

This is an information page for a one-person Gmail assistant. It is not a sign-in page and it cannot grant access to Gmail.

Current status

One personal account has active Gmail read-only, Gmail send, and identity authorization, with a local token. Separately task-authorized selected-message inspections occurred, and selected headers and relevant text were processed by the assistant’s external OpenAI Codex model provider for those limited tasks.

A bounded read-only synthetic-subject detection trial ran and is now stopped. No current monitoring is enabled, and this was not authorization for unrestricted monitoring.

Active permissions

The active scopes are exactly:

  • https://www.googleapis.com/auth/gmail.readonly
  • https://www.googleapis.com/auth/gmail.send
  • openid
  • email
  • https://www.googleapis.com/auth/userinfo.email

The Gmail read-only scope can technically view all messages, settings, and attachments in the account. The Gmail send scope can technically send email as the account. The stored authorization does not include Gmail modify, compose, or full-mail scopes.

Google describes Gmail scopes in its Gmail API scope guide.

Intended purpose

The completed authorized uses are limited to separately task-authorized selected-message inspections, processing selected headers and relevant text through the external OpenAI Codex model provider for those limited tasks, and the separate bounded detection-only trial that is now stopped. The Gmail send capability is not authority: no message has been sent, and actual or automatic sending, mailbox mutation, and provider-side reply drafts are not authorized.

What has not been finalized

There is no settled public disclosure yet for where mail-related data would be stored, how long it would be retained, how deletion would work, or how backups and logs would be handled.

The existence of a local token does not settle token storage, unlock, security, or rotation details. Apart from those separately task-authorized inspection tasks, general future AI use, provider handling, data handling, log retention, and which message excerpts could be sent to a provider are not finalized.

Public contact information has not been supplied for publication. These unresolved items need owner and provider review before any further mailbox use.

Future revocation

The account owner can revoke the active grant through Google Account third-party connections. Removing the local token would be a separate step.
